## Behavioral safeguards

- Closing/reopening a form or switching its category preserves the unfinished draft.
- Saving another material section adopts the refreshed server revision without erasing dirty fields in hidden sections. Later saves use that current revision.
- Invalid hidden distribution or posting fields produce visible guidance; posting validation reveals the relevant category.
- Unavailable/loading setup queries are not interpreted as missing configuration. Suspended workspaces are not prompted to pay again.
- Empty, filtered-empty, loading and failed states remain distinct. Actions continue to respect permissions. Device pairing is gated by API-key management plus bridge permissions; resource declaration still needs capability management.
- All new strings are merged into both Turkish and English locale files; no prior locale keys were removed.

## Validation

**Final integrated checks passed: 66 Vitest files, 486 tests; TypeScript `tsc --noEmit`; Vite production build; `git diff --check`.** The build retains a non-blocking bundle-size warning (main chunk approximately 838 KB minified / 227 KB gzip); code splitting was not part of this UX pass. Family review snapshots contain earlier partial runs; superseded cross-family TypeScript and locale merge issues were resolved centrally. Browser calls used intercepted fixture APIs, not live accounts. Desktop/mobile checks cover document overflow, runtime errors and selected interactions. Planning verified 82 scenario-width cases, entry 42 unique variants, customer pages 20 captures, admin 10 routes at two widths with later focused recaptures, and capabilities four cases. The gallery additionally decoded all 58 images successfully. English/dark-mode entry scenarios were also checked.

Real OAuth authorization, telephony, camera permissions, bank approval, external publishing and full assistive-technology evaluation remain outside this local verification. Some substantive long records still require scrolling within their selected category.
